# Inputs para la Fase 2

Acá va el material que el architect-agent usa, junto con `docs/prd.md`, para diseñar la arquitectura. Con al menos uno alcanza:

- **Estructura:** mapa de pantallas, sitemap o módulos del sistema.
- **Flujo:** diagramas de proceso o flujos de usuario paso a paso.
- **Customer journey:** etapas, acciones del usuario, puntos de contacto y emociones o fricciones.

## Formatos que el agente puede leer

- Markdown (`.md`): el formato más confiable. Un paso por línea o una tabla con columnas tipo etapa · acción · pantalla · dato que se usa.
- Imágenes (`.png`, `.jpg`): capturas de Miro, FigJam o Figma. Funcionan, pero el agente puede malinterpretar un diagrama denso. Si es crítico, acompañalo con una versión en texto.
- Mermaid dentro de un `.md`.

## Nombres sugeridos

- `journey.md` o `journey.png`
- `flujos.md`
- `estructura.md`

No hace falta que estén completos: lo que falte, el agente lo pregunta.
